# ContextApp

Aplicación móvil construida con **React Native**, diseñada para explorar y demostrar el manejo del estado global utilizando **Zustand** y navegación con **React Navigation**.

## 🚀 Stack Tecnológico

- **React Native 0.79**
- **React 19**
- **Zustand** para manejo de estado
- **React Navigation** para navegación entre pantallas
- **TypeScript**

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/contextapp.git

# Entrar al proyecto
cd contextapp

# Instalar dependencias
npm install
```

  ## 📱 Ejecutar la App

### Android

```bash
npx react-native run-android
```
### iOS

```bash
npx react-native run-ios
```
